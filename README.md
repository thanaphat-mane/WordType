
#  Wordtype

### **โปรแกรมฝึกพิมพ์สัมผัสเพื่อเพิ่มทักษะและความเร็วในการพิมพ์และการเขียนโปรแกรม**


---

### เกี่ยวกับโปรเจกต์ (About The Project)

### **Wordtype** คือโปรแกรมที่ถูกพัฒนาขึ้นเพื่อช่วยให้ผู้ใช้งานสามารถฝึกฝนการ**พิมพ์สัมผัส (Touch Typing)** ได้อย่างถูกต้อง รวดเร็วมีสวนช่วยในการพัฒนาความเร็วและถูกต้องในการพิม

---

## คุณสมบัติเด่น (Key Features)

### -  **ฝึกพิมพ์สัมผัส (Touch Typing Practice):** บทเรียนและแบบฝึกหัดที่ออกแบบมาเพื่อพัฒนาความถูกต้องและความเร็วในการวางนิ้ว
### -  **วัดผลแบบ Real-time (Live Analytics):** คำนวณความเร็วในการพิมพ์ (WPM - Words Per Minute) และอัตราความแม่นยำ (Accuracy Rate)
### -  **ติดตามพัฒนาการ (Progress Tracking):** บันทึกประวัติและสถิติเพื่อดูความก้าวหน้าในการฝึกฝน

---

## เทคโนโลยีที่ใช้ (Tech Stack)

### - **Frontend:** Java
### - **Backend:** Java
### - **Tools & Version Control:** Figma,Canva,Github
